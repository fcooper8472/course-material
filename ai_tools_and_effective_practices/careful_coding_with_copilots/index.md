Courses for coding with generative AI (genAI) coding assistants. Each module is designed to be a software repository created with the help of a genAI coding assistant to solve a particular problem. The aim is for students to use genAI to "fix" the errors caused by unthinking usage of the tool, and gain deeper understanding of how to debug AI-generated code.
